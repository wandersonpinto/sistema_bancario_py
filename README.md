# Curso Python Dio

O objetivo do programa é criar um sistema bancário simplificado para um único usuário. Este sistema deve permitir três operações:

## Depósito:
  O usuário deve poder depositar valores positivos em sua conta bancária. Todos os depósitos devem ser registrados e exibidos no extrato.

## Saque: 
  O sistema deve permitir até três saques por dia, com um limite máximo de R$ 500,00 por saque. Se objetivo do programa é criar um sistema bancário simplificado, com as seguintes funcionalidades o usuário não tiver saldo suficiente, o sistema deve exibir uma mensagem de erro. Todos os saques devem ser registrados e exibidos no extrato.

## Extrato:
  Esta operação deve listar todos os depósitos e saques realizados na conta, exibindo o saldo atual da conta no final da listagem. Os valores monetários devem ser exibidos no formato R$ xxx.xx(ex:R$ 1500.45).
Em resumo, o programa visa simular as funcionalidades básicas de uma conta bancária, com foco em depósito, saque e consulta de extrato, respeitando as restrições especificadas para saques diários.
